# Sluice frontend

Angular app for Sluice. See the [root README](../README.md) for how to run, build and test it.

```
src/app/
  core/       app-wide: i18n (Transloco), layout (shell), generated API client
  shared/     reusable UI building blocks (from milestone 3)
  features/   one folder per feature, lazy loaded
```
